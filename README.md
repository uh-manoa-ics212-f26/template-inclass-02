# In Class Practice 01 Repository Guide

## Repository Setup Instructions

1. Navigate to the template.
2. Click the green **Use this template** button in the top right corner of the repository page.
3. Click "create a new repository".
4. Under **Owner**, select this organization (uh-manoa-ics212-f26).
5. Set the repository **Visibility** to **Private**.
6. Name your repository exactly like this: inclass=02-your_uh_username

---

## Provided Files

Within the template you will have the following files that are currently empty.

* `library.c`: Your code for this in class practice.

---

## Submission

Please push all your lab work (all code and written answers) to your repository. 

Practice 1 Submission: Each student must submit a copy of the pair's current library.c file at
the end of the first class session, even if incomplete.

All three submission checkpoints are mandatory. Incomplete work is acceptable for
the two in-class submissions, but the final submission must include all required functionality from
both practices.

## Late Work Policy

Assignments may be submitted up to **24 hours late with a 20% grade penalty**. Assignments submitted more than 24 hours after the deadline will not be accepted, except in circumstances approved by the instructor.
